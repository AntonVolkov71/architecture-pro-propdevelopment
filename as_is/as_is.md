### Архитектура доменная
- Группа сервисов для продаж
  - витрина продаж
  - client-tour-app (приложение для онлайн-тура) с БД
  - client-mart-app (приложение для онлайн-сделки) с БД
  - client-crm-app (система для управления клиентскими данными) с БД
  - client-mart-estate-app (приложение для управления данными о недвижимости) с БД
- Группа сервисов ЖКУ
  - витрина
  - tenant-core-app (сервис для предоставления услуг) и его БД
  - CRM, которая управляет данными о собственниках, и её БД.
- Финансы
  - система финансового учёта — accountant-service-1 с БД 
  - служба каталогов


### Инфраструктура
- Большинство на собственных серверах
- Часть в гибриде
- Для временного расширения используются облачные ресурсы
- приватное облако, собственный ЦОД
- БД с резервным копированием в глубину
- firewall для внешних пользователей

### Проблемы и потребности бизнеса
- Нарушен контроль данных
  - несколько точек регистрации нового клиент
  - Внутренние потоки данных между IT-продуктами контролируются не системно
  - Со стороны систем обработки данных нет ограничений на доступ к данным.
- проблемы с API партнёров
  - API без единых политик по безопасности и без системного контроля за передаваемыми данными
    - Контракты API содержат персональные данные.
    - контракты позволяют внешним пользователям выполнять действия и получать данные, к которым у них не должно быть доступа


### Цели аудита
- Повысить уровень удовлетворённости клиентов
  - жалобы клиентов
    - ошибки в ПО (отображение данных другого клиента)
- Компания не может расширять направление обработки данных
  - накоплено много данных, которые можно использовать в новых сервисах на базе BI-, ML- и AI-технологий.
- Отреагировать на инциденты и рыночные изменения.
  - была утечка у конкурента, необходимо не допустить у себя
- Проверить соответствие требованиям законодательства
  - новые процессы, интеграции не соответствуют законодательству
