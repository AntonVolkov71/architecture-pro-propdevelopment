  - умный дом

### Архитектура доменная
- Группа сервисов для продаж
  - витрина продаж
  - client-tour-app (приложение для онлайн-тура) с БД
  - client-mart-app (приложение для онлайн-сделки) с БД
  - client-crm-app (система для управления клиентскими данными) с БД
  - client-mart-estate-app (приложение для управления данными о недвижимости) с БД
- Группа сервисов ЖКУ
  - витрина
  - tenant-core-app (сервис для предоставления услуг) и его БД
  - CRM, которая управляет данными о собственниках, и её БД.
- Финансы
  - система финансового учёта — accountant-service-1 с БД 
  - служба каталогов
