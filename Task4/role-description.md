| Роль                      | Права роли                                                                            | Группы пользователей                                                           |
|---------------------------|---------------------------------------------------------------------------------------|--------------------------------------------------------------------------------|
| cluster-admin             | полный доступ ко всему во всех кластерах (ClusterRole)                                | Админы k8s, devops: devops-sa                                                  |
| cluster-security          | get/list/watch с доступом во все кластера с секретными данными, конфигами, политиками | Безопасник: security-sa                                                        |
| cluster-watcher           | get/list/watch с доступом во все кластера без секретных данных, конфигов, политик     | Сотруднки: менеджеры, бухгалтера, аналитики: watcher-sa                        |
| smarthome-namespace-admin | get,list,watch,create,update,patch для namespace связанного с Умным домом             | Администраторы, операторы интеграции сервиса Умный дом: smarthome-operator-sa  |
