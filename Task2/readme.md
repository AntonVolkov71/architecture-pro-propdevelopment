## Анализ схемы
- Группа сервисов клиентов
  - Витрина для подбора и бронирования объектов недвижимости
  - Приложение для управления информацией об объектах недвижимости
  - Приложение для: - предоставления информации об объектах недвижимости, - проведения онлайн-сделок
  - Приложение для проведения 3D-тура по объекту недвижимости (онлайн-тур
  - Система управления клиентскими данными
- Группа сервисов ЖКУ
  - Витрина сервисов для собственников
  - Приложение для предоставления услуг собственникам
  - Система управления данными собственников
- Внешние системы
  - Платежная система
  - Поставщик ресурсов ЖКХ
  - Государственные регистрационные органы
- Общие
  - Служба каталогов, которая обслуживает финансовые сервисы
  - Единое хранилище данных для всех систем компании
- Внутренние
  - Система бухгалтерского учёта

### Разделы для чек-листов
- Управление доступом
  - Причины
    - жалобы со стороны клиентов
    - единый сервис и хранение собственников и клиентов
  - Сервисы
    - Витрины
    - CRM
    - Служба каталогов, которая обслуживает финансовые сервисы


- Внешние системы (интеграции и партнёрские API)
  - Причины
    - нет единых политик безопасности
    - передаются персональные данные тем кому не положено
  - Сервисы
    - Приложение для предоставления услуг собственникам и Поставщики ЖКХ;
    - Приложение для: - предоставления информации об объектах недвижимости, - проведения онлайн-сделок и Государственные регистрационные органы


- Система управления клиентскими данными
  - Причины
    - сильная связанность от других сервисов
    - актуализация данных в соответствии с законодательством
  - Сервисы
    - Система управления клиентскими данными
    - Единое хранилище данных для всех систем компании

    
- Физическое хранилище данных DWH
  - Причины
    - единое место хранения 
    - хотелки компании расширить обработку данных
  - Сервисы
    - Физическое хранилище данных DWH
